⚽ Estrattore Formazioni AA

Questo tool legge i file Excel delle formazioni da Google Drive e genera un file JSON da allegare a Claude per aggiornare il sito.

⚠️ Prima di usare questo tool devi creare un progetto Google Cloud gratuito e ottenere un API Key. Segui i 3 step qui sotto.
1 Crea un progetto Google Cloud
Vai su console.cloud.google.com → clicca "Crea progetto" → dai un nome qualsiasi → clicca "Crea".

Poi vai su API e servizi → Libreria → cerca "Google Drive API" → clicca "Abilita".
2 Ottieni le credenziali OAuth
Vai su API e servizi → Credenziali → clicca "Crea credenziali" → scegli "ID client OAuth 2.0".

Tipo applicazione: Applicazione web.
In "Origini JavaScript autorizzate" aggiungi: null (per file locali) e l'URL completo di questa pagina se la ospiti.

In "URI di reindirizzamento autorizzati" aggiungi: https://localhost

Clicca "Crea" e copia il Client ID.
3 Inserisci il Client ID e avvia
Incolla il Client ID qui sotto, poi clicca "Avvia estrazione".
Il tool leggerà automaticamente le cartelle:
  • Campionato 2024/2025
  • Campionato 2025/2026
  • Coppa 2024/2025
  • Coppa 2025/2026
